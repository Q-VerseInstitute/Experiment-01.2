# THE ETERNAL WINTER: REITERATION

*A Q-Verse experimental survival modpack.*

> **The experiment will begin soon. Enjoy your stay.**

## Overview

**The Eternal Winter: Reiteration** is a custom Minecraft modpack developed for a Q-Verse survival experiment.

Set in a desolate, frozen world, the experience revolves around harsh environmental conditions, isolation, resource scarcity, and the need to prepare before venturing into the unknown.

Survival is only the beginning.

## Technical Information

- **Minecraft version:** 1.21.1
- **Mod Loader:** NeoForge
- **Loader version:** 21.1.264
